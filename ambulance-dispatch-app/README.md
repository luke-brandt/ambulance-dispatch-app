### Prerequisites

- Python3 installed (`python3 --version` to check)


### Getting started

1. **Clone the Repo**

2. **Create a virtual environment**

    ```bash
    python3 -m venv .venv
    ```

3. **Activate it**

   ```bash
   # macOS/Linux
   source .venv/bin/activate

   # Windows PowerShell
   .venv\Scripts\Activate.ps1

   # Windows Command Prompt
   .venv\Scripts\activate.bat
   ```

4. **Install dependencies**

    dispatch-app-PT2.py requires Networkx to be installed to run.

    ```bash
    pip install -r requirements.txt
    ```

### Running the file again

Re-activate the virtual environment:

```bash
source .venv/bin/activate
````
